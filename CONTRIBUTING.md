# Участие в разработке

1. Создайте ветку от `master` и откройте pull request. Не добавляйте реальные письма, чаты, задачи, ключи, базы и локальные каталоги приложения.
2. Для изменения приложения добавьте понятную пользователю запись в конец `CHANGELOG.md`: строку `- **EN:** ...`, затем `  **RU:** ...`. Документация и CI без изменения приложения не требуют записи.
3. Запустите `npm ci`, `npm run build`, `npm test` и `npm run desktop:build`. Отдельно укажите, что проверено только на fake-данных.
4. Опишите границы функции, способ проверки и ограничения. Работа с внешними источниками и моделями подчиняется `AGENTS.md`.
5. После review изменение попадает в `master`. Изменения приложения запускают релиз; CI вычисляет следующую patch-версию и публикует релиз только после сборки и проверки всех платформ.

Подробности сборки и подписи: [docs/release-and-updates.md](docs/release-and-updates.md).
