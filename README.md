# Контекст менеджера

Локальное desktop-приложение для ручного сбора рабочего контекста и подготовки проверяемого дайджеста. Первый срез использует только синтетические данные, fake Todoist и детерминированный fake AI-провайдер. Реальные аккаунты и внешние сервисы не подключены.

## Запуск

Требуются Node.js 20+, Rust toolchain и системные зависимости Tauri 2 для вашей ОС.
Скрипты автоматически находят Cargo в стандартном каталоге `~/.cargo/bin`, даже если он ещё не добавлен в `PATH` текущего терминала.

```sh
npm install
npm run desktop
```

Проверка:

```sh
npm run build
npm test
npm run desktop:build
```

Для локальной сборки подписанного релиза нужен ключ Tauri; в этом checkout он хранится в `.local/signing/`. Обычная `npm run desktop` работает без него. Публикация настроена отдельно в [документации релизов](docs/release-and-updates.md).

`npm run dev` запускает только webview-разметку; для работы локальных команд и сохранения Markdown откройте desktop-приложение через `npm run desktop`.

В интерфейсе откройте «Настройки», включите демонстрационные источники и сохраните. Нажмите «Собрать контекст». Дайджест и контекст сохранятся как Markdown в локальном каталоге данных приложения; абсолютные пути показываются под документами. Во вкладке «Предложения» отметьте задачу, проверьте текст и подтвердите создание. Запись идёт только в fake Todoist, ссылка задачи и журнал сохраняются локально.

Исходные тексты и настройки этого репозитория не содержат пользовательских данных. Каталог данных приложения, `.local/`, базы, ключи и артефакты сборки исключены из Git. Секреты для будущих подключений должны храниться в системном хранилище учётных данных.
